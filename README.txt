### Запис 1 — Персонаж і рух
Сьогодні я створив першу сцену MainScene і додав персонажа PlayerCharacter.
Написав свій перший скрипт PlayerController, який рухає персонажа клавішами WASD і стрілками.
Для цього використав Input System і дію MoveAction. Швидкість руху — 3 одиниці за секунду.
Щоб рух був однаковим на будь-якому комп'ютері, множу зсув на Time.deltaTime.
Також налаштував підлогу на тайлмапі: Pixels Per Unit = 64 та Order in Layer = -10.
Спочатку персонаж зникав під тайлмапом, але після зміни Order in Layer усе запрацювало.
